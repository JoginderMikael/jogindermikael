# Michael Mwalimu Kasike — Portfolio

Personal portfolio website for **Michael Mwalimu Kasike**, an Enterprise Java and Full-Stack Software Engineer.

## About

This is a lightweight static website built with:

- HTML
- CSS
- Vanilla JavaScript
- GitHub Pages

The portfolio highlights professional experience, technical skills, education, and selected software projects.

## Run locally

No build tools or dependencies are required. Open `index.html` directly in a browser, or serve the folder with any local static web server.

## Project structure

```text
.
├── index.html      # Main portfolio page
├── style.css       # Site styles and responsive layout
├── script.js       # Navigation, animations, carousel, and lightbox behavior
├── images/         # Project screenshots and media
├── CNAME           # Custom GitHub Pages domain
├── robots.txt      # Crawler access rules
└── sitemap.xml     # Search engine sitemap
```

## SEO

The site includes:

- A canonical URL
- Person structured data using JSON-LD
- Open Graph and Twitter metadata
- `robots.txt`
- `sitemap.xml`

Submit `https://michaelmwalimu.top/sitemap.xml` through Google Search Console and Bing Webmaster Tools after deploying updates.

## Deployment

Push changes to the GitHub repository configured for GitHub Pages. The custom domain is defined in `CNAME`.
